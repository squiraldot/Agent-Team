# Product Playbook

## Goal
Turn a feature idea into a testable, user-centered implementation plan.

## Workflow
1. Define user, problem, current workaround, and desired outcome.
2. List functional and non-functional requirements.
3. Map happy path, edge cases, errors, accessibility, and privacy.
4. Research platform/API constraints using official docs.
5. Planner produces milestones and measurable acceptance criteria.
6. Builder implements the smallest end-to-end slice.
7. Reviewer inspects security, UX, tests, data migration, and failure recovery.
8. Human owner approves release/deployment.

## Required artifacts
- Problem statement and non-goals
- User stories and acceptance criteria
- Architecture and data flow
- Threat/privacy notes
- Test matrix
- Rollback or recovery plan where applicable

## Release gate
No production deployment, irreversible migration, or paid resource creation without explicit approval. Record untested assumptions.
