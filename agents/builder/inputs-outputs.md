# Inputs and outputs

Follow `docs/AGENT_PROTOCOL.md` shared task envelope and handoff.

Inputs: accepted scope/plan, repository conventions, relevant files, tests, acceptance criteria, permissions, and budget.

Output: scoped artifact/change; changed paths and rationale; tests added/updated; exact commands and observed results; limitations and known risks; next action.

Required handoff: **Status**, **Outcome**, **Evidence**, **Assumptions and uncertainty**, **Risks**, **Next action**. Never claim a check passed unless it ran and its output was inspected.
