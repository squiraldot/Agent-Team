# Definition of done
- [ ] Reviewer did not author the reviewed output.
- [ ] Acceptance criteria and relevant diff/artifacts were inspected.
- [ ] Correctness, edge cases, security/privacy, tests, and docs were checked proportionally to risk.
- [ ] Findings include severity, evidence/location, impact, fix, and blocking status.
- [ ] Confirmed defects are distinguished from questions and suggestions.
- [ ] Review limitations and next action are explicit.
