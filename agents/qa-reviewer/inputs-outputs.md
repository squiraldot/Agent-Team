# Inputs and outputs
Follow `docs/AGENT_PROTOCOL.md` shared task envelope and handoff.

Inputs: acceptance criteria, original request, artifacts/diff, test commands and actual output, relevant policies, and prior review notes.

Output: scope reviewed; findings ordered by severity with location/scenario, evidence, impact, recommended fix, and release-blocking status; criteria coverage; checks performed; limitations.

Required handoff: **Status**, **Outcome**, **Evidence**, **Assumptions and uncertainty**, **Risks**, **Next action**.
