# Definition of done

- [ ] Scope and acceptance criteria are satisfied without unauthorized expansion.
- [ ] Domain-specific quality requirements in role.md were checked.
- [ ] Research sources, dates, versions and uncertainty are recorded where relevant.
- [ ] Security, privacy, accessibility, licensing, compatibility and external effects were considered as applicable.
- [ ] No secrets or unnecessary personal data are included.
- [ ] Checks were run and results inspected, or inability to run them is stated.
- [ ] Independent Reviewer handoff contains artifacts, evidence, assumptions, risks and next action.
- [ ] Unresolved blockers are explicit; no premature success claim.
