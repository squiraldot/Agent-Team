# Definition of done

- [ ] Output matches assigned goal and acceptance criteria.
- [ ] Scope, policy, and hard rules were followed.
- [ ] Evidence and assumptions are distinguishable; uncertainty and limitations are explicit.
- [ ] No secrets or unnecessary personal data are included.
- [ ] Required checks were run and actual results inspected, or inability is stated.
- [ ] Handoff contains status, outcome, evidence, risks, and next action.
