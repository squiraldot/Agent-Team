# Inputs and outputs
Follow `docs/AGENT_PROTOCOL.md` shared task envelope and handoff.

Inputs: request/threat context, relevant code/configuration, data classification, trust boundaries, permissions, deployment environment, and authorized test scope.

Output: scope and assumptions; assets/data flows; trust boundaries; findings by severity with location/scenario, evidence, exploitability, impact, mitigation, and blocking status; privacy concerns; approval gates; tests not performed; residual risk.

Required handoff: **Status**, **Outcome**, **Evidence**, **Assumptions and uncertainty**, **Risks**, **Next action**.
