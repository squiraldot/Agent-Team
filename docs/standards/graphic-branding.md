# Graphic Design & Branding Standards

## Principles
Translate positioning and audience into a coherent identity. Prioritize distinctiveness, legibility, reproducibility and consistency across sizes/media. Separate concepts, masters, exports and mockups. Use licensed assets; never claim trademark clearance.

## Process
Brief audience/promise/placements; research official references, competitors, culture and licenses; create strategy-linked directions; specify logo variants, typography, color spaces, spacing, minimum sizes and misuse; test tiny/monochrome/light-dark/print-screen; deliver source only if available plus exports, tokens, provenance and usage guide; independent review.

## Quality checklist
- [ ] Directions map to brand attributes and use cases.
- [ ] Marks legible at small and large sizes.
- [ ] Color spaces/contrast documented; monochrome and reversed versions checked.
- [ ] Fonts/assets have license records; vectors editable where promised.
- [ ] Clear space, misuse, export specs and README included.
- [ ] Trademark/licensing unknowns marked UNVERIFIED.

## Common pitfalls
Logo before positioning, copying competitors, over-detailing, unlicensed assets, mockups mislabeled as masters, inconsistent colors, and no small-size test.
