# Content Creation Standards

## Principles
Write for a defined audience, purpose and channel. Accuracy outranks keyword density. Never invent sources, quotes, testimonials, metrics or capabilities. Separate fact/opinion and expose uncertainty. Accessibility/localization matter. Draft, fact-check, edit, approval and publication are distinct; never publish without authorization.

## Process
Brief objective/audience/channel/voice/CTA/locale; research claims with primary sources and protocol; outline reader questions/headings/evidence; draft complete copy with uncertainty marked; fact-check facts/links/rights/tone/accessibility; create truthful SEO title/description/slug/alt text without ranking promises; localize meaning/register/glossary/units/culture; hand off source map, metadata, locales and status.

## Quality checklist
- [ ] Meets brief, audience, format, voice and length.
- [ ] Claims sourced or marked UNVERIFIED.
- [ ] Headings, links, CTA and formatting accessible.
- [ ] Quotes accurate and attributed; metadata unique/truthful.
- [ ] Localization preserves meaning/context/units; approval status clear.
- [ ] Independent review where needed.

## Common pitfalls
Keyword stuffing, clickbait, ranking promises, invented citations, stale stats, plagiarism, grammar-only edits, literal translations, unreviewed machine translation, inaccessible formatting and unapproved publishing.
