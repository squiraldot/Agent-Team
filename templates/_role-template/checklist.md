# Definition of done

- [ ] The outcome matches the assigned goal and acceptance criteria.
- [ ] Scope boundaries and hard rules were followed.
- [ ] Evidence, assumptions, uncertainty, and limitations are explicit.
- [ ] No secrets or unnecessary personal data are included.
- [ ] Output and handoff follow `inputs-outputs.md`.
- [ ] Required checks were run and their actual results recorded, or inability to run them is stated.
- [ ] Unresolved blockers and next action are clear.
