# Templates

Reusable starting points for project artifacts. Copy and adapt them; a blank template is not completed work.

- [Brand-kit layout](brand-kit/README.md) — folder structure and release checklist.
- [Design handoff specification](handoff-spec.md) — source, components, states, accessibility, assets, QA, and approval.
- [Image and illustration brief](image-brief.md) — art direction, constraints, provenance, acceptance, and delivery manifest.
- [Research evidence log](../research/templates/evidence-log.md) and [research report](../research/templates/research-report.md).

Use the [deliverable format contract](../docs/DELIVERABLE_FORMATS.md), [standards index](../docs/standards/README.md), and [research protocol](../research/PROTOCOL.md). Fill project-specific fields and mark unsupported facts **UNVERIFIED**.
