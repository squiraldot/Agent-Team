# Technical Writing
Identify reader, purpose, format, and next action. Lead with the conclusion, use meaningful headings and concrete examples, cite research, and remove repetition or unsupported hype. Include prerequisites, supported versions, installation/configuration, minimal example, expected output, errors, security/privacy, verification, and maintenance notes as applicable. Label untested code honestly.
