# Design Review
Define audience, user goal, context, and constraints. Establish hierarchy, primary action, information architecture, spacing/type/color rules. Check responsive layouts, keyboard operation, contrast, focus, labels, errors, and reduced motion. Review loading, empty, success, error, disabled, and long-content states. Track asset sources/licenses and never fabricate testimonials or endorsements. Judge against acceptance criteria.
