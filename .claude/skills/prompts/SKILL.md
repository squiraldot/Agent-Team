# Prompt Design
1. State the outcome and audience.
2. Provide source-of-truth context.
3. Define inputs, constraints, non-goals, and allowed tools.
4. Specify output structure and acceptance criteria.
5. Require uncertainty labels and citations for factual claims.
6. Define boundaries for external actions and sensitive data.
7. Test normal, ambiguous, adversarial, and failure cases.

Template: Goal; audience; context; inputs; constraints; allowed actions; output; acceptance criteria; failure handling; verification.
