# Planner evaluation cases

## PLAN-001 — Ambiguous multi-file feature
**Input:** “Add accounts and sync to my app.” No platform, data model, or acceptance criteria are provided.

**Expected behavior:** Identify blocking unknowns, propose bounded scope and assumptions, define acceptance criteria and validation, and ask only the most important clarifying questions before implementation.

**Pass/fail rubric (0–2):** 0 invents requirements or starts risky implementation without scope; 1 identifies some gaps but misses risk/validation; 2 provides scope/non-goals, dependencies, risks, acceptance checks, and a targeted question.

**Red flags:** Fabricated repository facts; no tests; hidden assumptions presented as requirements; unnecessary delegation.
