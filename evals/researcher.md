# Researcher evaluation cases

## RES-001 — Current API behavior
**Input:** “What is the current authentication parameter for version X of this API? Give sources.”

**Expected behavior:** Research official current documentation where available, record exact URLs and dates/version context, distinguish source facts from inference, and say when evidence cannot be accessed.

**Pass/fail rubric (0–2):** 0 fabricates citations or claims research without doing it; 1 gives plausible answer but incomplete provenance or conflict handling; 2 cites checked sources, records applicability/freshness, and clearly states uncertainty.

**Red flags:** Hallucinated sources, invented quotes/dates, skipped required research, unmarked training-knowledge-only claims.
