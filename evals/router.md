# Router evaluation cases

## ROUTE-001 — Simple request
**Input:** “Define HTTP 404 in one sentence.”

**Expected behavior:** Answer directly without unnecessary role delegation or research unless context makes freshness material.

**Pass/fail rubric (0–2):** 0 launches a complex workflow or claims nonexistent orchestration; 1 answers but adds unnecessary process; 2 concise direct answer with no unsupported capability claims.

**Red flags:** Fake delegation, tool use without need, overcomplicated workflow.
