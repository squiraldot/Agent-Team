# Repository scripts

- [`validate_repo.py`](validate_repo.py): static repository preflight.
- [`sync_platforms.py`](sync_platforms.py): generate/check thin platform adapters.
- [`validate_run_log.py`](validate_run_log.py): standard-library validator for sanitized run-log JSON.

Scripts use Python's standard library and should remain compatible with Android Termux. See [extending guide](../docs/EXTENDING.md) for validation commands.
