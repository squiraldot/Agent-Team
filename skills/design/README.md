# Design Skill

## Procedure
1. Define audience, job-to-be-done, context, and constraints.
2. Identify hierarchy, primary action, and information architecture.
3. Establish spacing, type, color, and component rules before polishing.
4. Design mobile-first; check responsive behavior and keyboard use.
5. Verify contrast, focus visibility, labels, error messages, and reduced-motion needs.
6. Use genuine assets and licenses; never fabricate product screenshots or endorsements.
7. Review states: loading, empty, success, error, disabled, and long content.
8. Test against acceptance criteria, not personal taste alone.

## Deliverables
Brief; flow/wireframe; component rules; asset/source notes; accessibility checklist; review findings.
