# Prompt Design Skill

## Procedure
1. State role and desired outcome, not theatrical persona.
2. Provide relevant context and source-of-truth files.
3. Specify constraints, non-goals, and permitted tools.
4. Define output schema and acceptance criteria.
5. Include examples only when they clarify behavior.
6. Require uncertainty labels and source attribution for factual claims.
7. Add safety boundaries for external actions and sensitive data.
8. Test the prompt on normal, ambiguous, adversarial, and failure inputs.
