# Automation Skill

- Prefer deterministic code for deterministic checks.
- Make operations idempotent where possible.
- Set timeouts and bounded retries.
- Log status, not secrets or unnecessary personal data.
- Provide dry-run mode for destructive/external actions.
- Require approval before publish/send/deploy/purchase/delete.
- Handle partial failure and cleanup explicitly.
- Document permissions, dependencies, tests, and recovery.
