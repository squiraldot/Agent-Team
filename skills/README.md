# Reusable Skills

A skill is a reusable procedure for a class of tasks. Keep each skill focused and invoke it only when relevant.

- [Prompts](prompts/README.md)
- [Research](research/README.md)
- [Writing](writing/README.md)
- [Design](design/README.md)
- [Automation](automation/README.md)

Agent definitions describe who performs a task; skills describe how to perform it.
