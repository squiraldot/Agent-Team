# Research Skill

## Evidence hierarchy
1. Official product/API docs, standards, release notes, and source code.
2. Maintainer-authored examples and active upstream repositories.
3. Peer-reviewed or established technical publications.
4. Reputable secondary reporting.
5. Community posts as leads, not sole evidence for critical claims.

## Procedure
- Convert the question into claims that can be checked.
- Search for current official documentation and version notes.
- Open sources; inspect the relevant section, not just search snippets.
- Check dates and distinguish release date from page update/crawl date.
- Verify critical claims with another independent source.
- Capture exact URLs, access date, applicability, and caveats.
- Report disagreement and missing evidence honestly.
