# Writing Skill

## Procedure
1. Identify reader, purpose, format, and next action.
2. Lead with the main answer or decision.
3. Use headings that communicate conclusions.
4. Prefer concrete examples and active voice.
5. Keep claims proportional to evidence; define unfamiliar terms.
6. Cite research and label assumptions.
7. Remove repetition, filler, unsupported superlatives, and misleading certainty.
8. Review for accessibility, inclusive language, and copy/paste usability.

## Technical documentation checklist
- Prerequisites and supported versions
- Installation and configuration
- Minimal working example
- Expected output
- Error handling and troubleshooting
- Security/privacy considerations
- Verification steps
- Maintenance/version notes
